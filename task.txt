Pro MVP bych připravil něco, co můžeš rovnou založit jako GitHub repozitář a spustit lokálně nebo přes GitHub Actions.

## MVP rozsah

### Agent 1 – Opportunity Scout

Sleduje:

* Musical Chairs
* Muvac
* české orchestry (ručně definovaný seznam)

Výstup:

```json
{
  "title": "Principal Violin",
  "organization": "Filharmonie Brno",
  "url": "...",
  "source": "muvac",
  "content": "..."
}
```

### Agent 2 – Evaluator

Pomocí OpenAI:

* extrakce pozice
* extrakce orchestru
* klasifikace relevance
* vytvoření shrnutí

### Notifikace

* e-mail (SMTP)
* Slack webhook

### Uložení

SQLite

    source = Column(String)

# Evaluator

```python
from openai import OpenAI

client = OpenAI()

def evaluate(text: str):
    response = client.responses.create(
        model="gpt-5",
        input=[
            {
                "role": "user",
                "content": text
            }
        ]
    )

    return response.output_text
```

# Email notifier

```python
import smtplib
from email.message import EmailMessage

def send_email(subject, body):
    msg = EmailMessage()

    msg["Subject"] = subject
    msg["From"] = SMTP_USER
    msg["To"] = RECIPIENT

    msg.set_content(body)

    with smtplib.SMTP_SSL(
        SMTP_HOST,
        SMTP_PORT
    ) as smtp:
        smtp.login(
            SMTP_USER,
            SMTP_PASSWORD
        )
        smtp.send_message(msg)
```

# Hlavní orchestrátor

```python
def run():
    opportunities = []

    opportunities.extend(fetch_muvac())
    opportunities.extend(fetch_musicalchairs())
    opportunities.extend(fetch_czech_orchestras())

    for opp in opportunities:

        if exists(opp.url):
            continue

        result = evaluate(opp.content)

        save(result)

        if result["score"] >= 80:
            notify(result)
```

# GitHub Actions

`.github/workflows/run.yml`

```yaml
name: Orchestra Agent

on:
  schedule:
    - cron: "0 */6 * * *"

jobs:
  run:
    runs-on: ubuntu-latest

    steps:
      - uses: actions/checkout@v4

      - uses: actions/setup-python@v5
        with:
          python-version: "3.12"

      - run: pip install -r requirements.txt

      - run: python main.py
        env:
          OPENAI_API_KEY: ${{ secrets.OPENAI_API_KEY }}
          SMTP_USER: ${{ secrets.SMTP_USER }}
          SMTP_PASSWORD: ${{ secrets.SMTP_PASSWORD }}
          SLACK_WEBHOOK: ${{ secrets.SLACK_WEBHOOK }}
```
